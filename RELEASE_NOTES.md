MarkView 2.0.1 adds the desktop entry and app metadata that were missing from the 2.0.0 Flatpak, so MarkView now shows up in the app grid and in software centres with its icon.

If you installed the 2.0.0 Flatpak bundle, install this one over it (or remove 2.0.0 first with `flatpak uninstall io.github.v8v88v8v88.MarkView`).

See the [2.0.0 release](https://github.com/V8V88V8V88/MarkView/releases/tag/v2.0.0) for everything new in MarkView 2.0.
